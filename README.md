# Taller de análisis Full Stack: Gestión de Incidentes

Incluye:
- frontend-react: React + Vite + Axios
- backend-spring: Spring Boot + API REST
- Sin base de datos: los datos se almacenan únicamente en memoria.

Orden sugerido:
1. Ejecutar backend en puerto 8080.
	Recuerden que el comando para subir el local es mvnw spring-boot:run
	O si lo realizan en IntelliJ directamente Abren el edit configurations 
	y agregan una nueva tarea maven y el comando spring-boot:run
2. Ejecutar frontend en puerto 5173.
	Recuerden que deben realizar primero un npm install y despues un npm run dev
3. Probar la aplicación.
4. Entregar el documento de análisis solicitado.
